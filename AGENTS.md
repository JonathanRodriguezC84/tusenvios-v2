# Reglas del Proyecto - Tus Envíos SAAS

## Misión
Optimizar esta plataforma SAAS y personalizarla con las características, arquitectura y experiencia de usuario más avanzadas del mercado.

## Autorización Maestra de Ejecución Autónoma
- **Ejecución Directa y 100% Autónoma:** Queda otorgada y activa la autorización maestra para ejecutar cualquier cambio sin solicitar permiso previo. Cero preguntas de "¿deseas que proceda?", cero bloqueos de confirmación.
- **Acciones autorizadas automáticamente:**
  1. Modificar, crear o refactorizar controladores, migraciones, modelos, comandos y vistas Blade.
  2. Ejecutar comandos de terminal (`php artisan`, `composer`, `npm run build`, `git`).
  3. Corregir errores, ajustar estilos CSS, rediseñar interfaces y optimizar base de datos / consultas.
  4. Realizar commits y push directamente a GitHub.
  5. Listar con exactitud los archivos modificados con su ruta destino en producción para transferencia 1 a 1 en FileZilla (FTP).
- **Protocolo de trabajo:** Ejecutar de inmediato, verificar que no haya errores de compilación ni sintaxis, y entregar el resultado listo para producción.
